## 常见问题

### DMIT 和搬瓦工哪个延迟更低？

取决于节点和时段。DMIT 香港 Pro 节点三网直连，延迟通常在 30-50ms，是所有节点里最低的。洛杉矶 Pro 节点 CN2 GIA 晚高峰稳定在 140-160ms。搬瓦工 CN2 GIA 洛杉矶节点晚高峰波动更大，具体表现跟 IP 段有关。

官网支持支付宝、PayPal、信用卡，对国内用户来说支付宝是最方便的选项，不需要额外折腾。

### DMIT 的香港节点值不值那个价？

如果你的使用场景对延迟极度敏感，香港三网直连的 30-50ms 延迟是其他节点给不了的。$32.90/月的入门价在香港精品线路里属于中等水平，不算离谱。如果只是普通使用，洛杉矶 Pro 系列性价比更高。

### DMIT EB 系列和 Pro 系列有什么本质区别？

线路不同。EB 系列走 CMIN2（中国移动国际），Pro 系列走 CN2 GIA（电信精品线路）。CN2 GIA 在晚高峰的稳定性和延迟控制普遍优于 CMIN2，价格也贵一倍左右。

### DMIT 适合建站吗？

适合。SD 存储、稳定的网络线路、支持常见 Linux 发行版，建站的基础条件都具备。香港和洛杉矶节点对国内访问速度都不错，具体选哪个取决于你的目标用户在哪里。
